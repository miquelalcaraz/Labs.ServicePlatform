# Épica 1 — Inicialización de Suscripción y Creación del Tenant para un Cliente B2B

**Objetivo de la épica**

Permitir que un *Project Manager* de **QLT System** inicialice correctamente un nuevo cliente en la plataforma B2B tras el cierre de una venta. Esta inicialización debe crear la estructura básica de la cuenta del cliente dentro del sistema, incluyendo la suscripción, el tenant asociado, la empresa propietaria y el usuario administrador que gestionará la plataforma desde el lado del cliente.

---

## Contexto

QLT System comercializa una plataforma B2B a través de su equipo de **comerciales**, quienes se encargan de cerrar acuerdos con empresas clientes. Una vez finalizada la venta, la implementación del servicio pasa a manos de un **Project Manager**, responsable de configurar el entorno inicial del cliente dentro de la plataforma.

Para facilitar esta configuración, el sistema dispone de un **Backoffice interno** desde el cual los Project Managers pueden crear y configurar las instancias necesarias para cada nuevo cliente.

Cada cliente debe operar en un entorno aislado dentro de la plataforma mediante un **modelo multi-tenant**, permitiendo además que en el futuro puedan añadirse otras empresas relacionadas dentro del mismo tenant.

---

## Descripción de la Épica

Esta épica cubre la **creación e inicialización de un nuevo cliente en la plataforma B2B** a partir de una venta cerrada.

Desde el Backoffice, el Project Manager podrá registrar la nueva suscripción del cliente. Este proceso deberá generar automáticamente la estructura base necesaria para que el cliente pueda comenzar a operar en la plataforma.

El flujo de inicialización incluye:

1. **Creación de la Suscripción**
    - Se registra una nueva suscripción asociada al cliente.
    - La suscripción determina el nivel de servicio y funcionalidades disponibles en la plataforma.
2. **Creación del Tenant**
    - El sistema crea un **tenant independiente** que representará el espacio organizativo del cliente dentro de la plataforma.
    - Este tenant permitirá en el futuro alojar múltiples empresas relacionadas dentro del mismo ecosistema.
3. **Creación de la Empresa Propietaria**
    - Dentro del tenant se crea la **empresa principal**, que será la propietaria de la suscripción.
    - Esta empresa representa al cliente que ha contratado la plataforma.
4. **Creación del Usuario Administrador**
    - Se crea un **usuario administrador inicial**, asociado a la empresa propietaria.
    - Este usuario tendrá el **máximo nivel de permisos permitido por la suscripción** y será el responsable de gestionar la plataforma desde el lado del cliente.
5. **Relaciones entre entidades**
    - La **suscripción** queda asociada a la empresa propietaria.
    - El **tenant** agrupa todas las empresas del cliente.
    - La **empresa propietaria** pertenece al tenant.
    - El **usuario administrador** pertenece a la empresa propietaria.

---

## Resultado esperado

Al finalizar este proceso:

- El cliente tendrá un **tenant activo en la plataforma**.
- Existirá una **empresa propietaria asociada a la suscripción**.
- Se habrá creado un **usuario administrador** que podrá acceder a la plataforma y comenzar a gestionar su entorno.
- La estructura del tenant permitirá **añadir futuras empresas relacionadas** dentro del mismo ecosistema B2B.
